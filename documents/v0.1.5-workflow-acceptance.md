# 0.1.5 工作流程与验收

本次仅修改飞书插件，沿用已发布的 SDK 网关和三项飞书权限。

消息页默认打开，先生成草稿，在同一页修改收件人和正文，明确确认后发送。与原生浮窗共享草稿 ID；迟到的旧快照不覆盖新编辑，发送中与结果不确定时禁止重复提交。发送结果保留至用户主动关闭。

任务页默认查看未完成任务，行内创建、搜索与筛选分区，详情展示完整内容和来源。日程页将行内创建放在日期与视图工具栏之前。切换工作区保留创建要求和回执；管理设置、联系人与操作记录分离。

原生表单提交在现有插件沙箱中不可用，所有新增提交按钮均使用普通按钮显式调用 SDK，不要求放宽宿主沙箱。

2026-11-05 在已安装 ViTalk 0.6.19 的开发插件页面完成：

- 创建仅当前账号的“飞书插件布局验收20261105-2025”任务，收到创建回执，刷新后查到任务；完成该任务后收到“飞书已确认任务完成”。
- 创建仅当前账号的“飞书插件布局验收20261105”日程，在飞书日历查询到 2026-11-06 15:00–15:30。
- 生成发给当前账号的消息草稿，检查收件人与正文后点击确认；收到真实消息 ID，页面保留“消息已发送”，发送按钮禁用。

这些验收覆盖真实 SDK 和飞书回执，不等同于物理麦克风验收，也不证明所有平台均完成桌面验收。

本版没有增加宿主未发布的任务编辑、删除、日程删除、消息撤回接口，也没有改变原生 LLM 解析器或通讯录权限规则。详情提供飞书来源跳转，源端管理行为仍由飞书处理。
