# 授权界面状态修复（2026-11-05）

用户反馈：正式安装版同时显示已连接、二维码和等待授权回执，操作按钮不可用。

## 已证实的问题与修改

- 原账号 connected 与本次 pendingAuthorization 是独立状态。存在待确认流程时显示“等待本次授权”，避免把旧连接当成本次成功。
- 等待设备回执时原先将官方授权链接一并锁住，现在保留打开入口，不重复发起 complete。
- 空闲时接收父页面状态同步二维码；本地授权请求中不接受被动快照覆盖流程。
- complete 返回后仅在 connected 且无后续 pendingAuthorization 时结束流程和同步通讯录。
- 浏览器打开错误独立保存，迟到的成功不会清掉授权失败信息。

## 验证

三个新增回归测试先失败，修复后通过；增加授权失败后浏览器迟到返回的回归测试。完整 51 项 Vitest、1 项原生依赖打包校验、TypeScript 检查通过。独立代码复核通过，已处理异步清错建议。

正式安装版只读 UI 检查确认仍有等待回执和禁用链接。现有日志没有对应设备回执记录，不能据此认定飞书侧未授权或已收到本次回执。Windows 点击工具返回 `coordinate input geometry is unavailable`，没有通过点击刷新验证现场恢复。

本次只修改插件界面，不修改权限范围、凭据、CLI 归属或桌面安装包。不把组件回归测试等同于真实飞书设备授权端到端验收；公开包尚未替换。
